# 🎯 Pokémon Ditto — Ability Info

Учебный проект по теме **«Асинхронный JavaScript»**. Демонстрирует работу с HTTP-запросами через `XMLHttpRequest`: получение данных о покемоне и последовательный запрос за деталями его способности.

---

## 📖 Описание задачи

1. Отправить GET-запрос на `https://pokeapi.co/api/v2/pokemon/ditto`
2. Из ответа получить ссылку на **первую способность** покемона
3. Отправить **второй запрос** по этой ссылке
4. Найти описание способности на **английском языке**
5. Вывести описание в консоль

---

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- XMLHttpRequest
- REST API: [PokéAPI](https://pokeapi.co/)

---

## 🚀 Запуск проекта

1. Скачайте все файлы в одну папку
2. Откройте `index.html` в любом браузере
3. Результат появится на странице, а описание — в консоли (**F12 → Console**)

> Дополнительной установки не требуется — проект работает без сервера и зависимостей.
